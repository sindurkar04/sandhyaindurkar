# sandhyaindurkar

Next.js app for deployment on [Vercel](https://vercel.com).

## Local development

Use Node.js 20+ (or the portable Node under `.tools/` if you use the same bootstrap as this repo).

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Push to GitHub, import the repository in the Vercel dashboard, then add your custom domain and update DNS at your registrar (Squarespace).
